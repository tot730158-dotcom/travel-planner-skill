## 使用方式

- **手機／平板閱讀**：直接開啟 HTML，內容為單欄自適應版面。
- **列印成 PDF**：用瀏覽器開啟 HTML →「列印」→ 目的地選「另存為 PDF」→ 紙張 A4 → 勾選「背景圖形」。
- **直接列印**：使用 PDF 檔即可，已設定頁碼、章節名稱與日期。

## 資訊分級原則

手冊內所有資訊均標示為：**已確認／已預訂、一般建議、待確認、以官方公告為準**。
凡 2026 年尚未公布或無法查證的班次、票價、營業狀態與釣點開放範圍，一律標示「待確認」，
並在「行前確認清單」與「行前資訊更新紀錄」提供查證項目與官方 QR Code。
